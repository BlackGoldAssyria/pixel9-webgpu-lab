2 · Cumulative WebGPU memory probe

Start conservatively. This test holds successive GPU storage buffers, clears them on the GPU, and verifies five nonzero sample writes via readback. It may cause Chrome to slow down or close. It does not measure physical VRAM or prove all model weights will fit. Do not run alongside a loaded model.

One 32 MiB buffer per step. Success means the buffers were allocated, GPU-cleared and sample-checked, not that there is that much unused RAM. High-risk limits (above 1,024 MiB) require an extra confirmation and can crash the browser. Memory progress checkpoints (numbers only) are saved locally so a crash can be recognised after reopening.
